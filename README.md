# App Masónica V0.1 — Primera fase visual consolidada (6/6)

## Arranque
Abrir `index.html` en Chrome, Safari o Firefox actualizado. Alternativa: desde esta carpeta ejecutar `python3 -m http.server 8000` y visitar `http://localhost:8000`. No necesita internet ni instalación de dependencias.

## Etapas integradas
1. Base visual y navegación: identidad, paleta y escudos locales.
2. Dashboard: métricas sin datos oficiales, accesos, actividad vacía y panel de cuerpos.
3. Miembros: directorio vacío por defecto, búsqueda y filtros sobre demostración opcional.
4. Expediente: ficha única visual con secciones Personal, GL, SCG33 y RA, VOE condicional.
5. Catálogos: Logias, Grados, Cargos, Títulos, Períodos y Estados, con acciones DEMO no persistentes.
6. Integración: rutas de accesos rápidos hacia catálogos concretos, validación de recursos y documentación.

## Límites
No hay autenticación, base de datos, guardado, nube ni datos institucionales reales. Los ejemplos están claramente marcados como ficticios. No se ejecutan sanciones, Concordato, irradiación, revisión ni VOE real. Los controles deshabilitados son deliberados; las acciones de catálogo son únicamente demostrativas.

## Comprobación
Consultar `ETAPA6_PRUEBAS.md`. Para la fase funcional aportar este ZIP, el Excel maestro más reciente y escudos únicamente cuando se requiera verificarlos o sustituirlos.
